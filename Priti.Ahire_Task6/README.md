# Laundry Mart Login Page

This is a simple login page created using HTML and CSS. The layout is made using CSS Flexbox.

## Features

- Flexbox layout
- Laundry image on the left
- Login form on the right
- Email and password fields
- Login button
- Register link

## Technologies Used

- HTML
- CSS

## How to Run

1. Download or extract the project folder.
2. Open the folder.
3. Double-click `index.html` or open it in any web browser.
