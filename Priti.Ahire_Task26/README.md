# Task 26 - Reusable React Card Component

## Overview

This project demonstrates a reusable React Card component.

The card receives an array of objects through props and uses the map() method to display multiple cards.

## Features

- Reusable React Card component
- Props for passing data
- Array of objects
- map() for rendering cards
- Gradient card border

## Technologies

- React
- JavaScript
- CSS
- Vite
