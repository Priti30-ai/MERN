# 🍴 OmniFood – Food Delivery Landing Page

OmniFood is a responsive food delivery landing page created using **HTML5 and CSS3**.

This project is designed as a practical assignment to demonstrate the use of **semantic HTML, CSS Flexbox, CSS Grid, responsive design, background images, overlays, buttons, cards, and media queries**.


## 📌 Project Overview

OmniFood is a modern food delivery website where users can:

* Explore healthy food delivery services
* Learn how the service works
* View available cities
* Read customer testimonials
* Check different pricing plans
* Sign up for a plan
* Find app download options

The website is designed to work properly on **desktop, tablet, and mobile devices**.

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic elements
* **CSS3** – Styling and layout
* **CSS Flexbox** – Flexible layouts
* **CSS Grid** – Cards and section layouts
* **CSS Media Queries** – Responsive design
* **Google Fonts** – Website typography
* **Font Awesome / CSS icons** – Icons and symbols

> No Bootstrap, Tailwind CSS, or other CSS frameworks are used.

## 📱 Responsive Design

The website is designed to work on different screen sizes.

### 💻 Desktop

For screens larger than 1200px:

* Full navigation menu
* Four-column city grid
* Three-column testimonials
* Three-column pricing cards
* Two-column How It Works section

### 📱 Tablet

For screens up to 834px:

* Content becomes more compact
* City cards use two columns
* Sections stack where required
* Navigation becomes more compact
* Pricing cards adjust to available space

### 📱 Mobile

For screens up to 390px:

* Single-column layout
* Navigation becomes a stacked menu
* Buttons stack vertically
* City cards use one column
* Pricing cards use one column
* Images resize proportionally
* Text size is reduced for readability
* Horizontal scrolling is prevented


## ▶️ How to Run the Project

### Step 1: Download or Clone the Repository

Download the project ZIP file or clone the repository using Git.

git clone YOUR_GITHUB_REPOSITORY_LINK


### Step 2: Open the Project

Open the `OmniFood` folder in **Visual Studio Code**.

### Step 3: Check the Assets

Make sure all images are inside the:

assets/folder.

The image filenames should match the filenames used in `index.html` and `style.css`.

### Step 4: Run the Website

Open `index.html` in a web browser.

You can also use the **Live Server** extension in Visual Studio Code.

Right-click on `index.html` and select:

Open with Live Server

The OmniFood website will then open in your browser.
