About This Project

This project demonstrates how to create a basic web server using Node.js and the built-in HTTP module.

It uses the File System module to read page files asynchronously, the Path module to build safe file paths, and URL routing to select the response and HTTP status code.

Technologies Used

  • Node.js
  • HTTP Module
  • File System Module
  • Path Module
  • HTML5
  • CSS3

Server Features

  • Multiple URL routes
  • Asynchronous file reading
  • HTTP status codes
  • Custom 404 page
  • Static CSS file serving
