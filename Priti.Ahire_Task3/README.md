# Task 3 - CSS Selectors

This project demonstrates the use of different CSS selectors to style an HTML webpage. The webpage is created using semantic HTML elements and an external CSS stylesheet.

## 📌 Project Overview

The purpose of this task is to understand and implement different types of CSS selectors, including:

* Universal Selector
* Element Selector
* Class Selector
* ID Selector
* Pseudo-class Selector

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Priti.Ahire_Task3/

```

## ✨ Features

* Responsive webpage layout
* Attractive gradient background
* Three different heading elements
* Class selector implementation using `.head`
* ID selector implementation using `#bglime`
* Paragraph styling using the element selector `p`
* Special styling for the second paragraph using `#para`
* Unordered and ordered lists
* Styling of the word "here" without using a class or ID
* Hover effect using a CSS pseudo-class
* External CSS file
* Semantic HTML structure
* No inline CSS
* No `<div>` element used

## 🎯 CSS Selectors Demonstrated

### 1. Universal Selector

```css
* {
    margin: 0;
    padding: 0;
}
```

### 2. Element Selector

```css
p {
    color: white;
}
```

### 3. Class Selector

```css
.head {
    color: darkblue;
}
```

### 4. ID Selector

```css
#bglime {
    color: red;
}
```

### 5. Pseudo-class Selector

```css
a:hover {
    color: red;
}
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the webpage and hover over the "here" link to see the interactive CSS effect.
