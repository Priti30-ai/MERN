# Task 29 - Shoe Store App

This project is a React + Vite shopping cart application for a shoe store.

## Features
- Product listing page
- Add to cart functionality
- Quantity update and item removal
- Cart summary and total price
- Payment page with cash/card options
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```
