# Tailwind Hero Landing Page

## Project Workspace

This project is a modern hero landing page created using HTML and Tailwind CSS.

The webpage represents a connected digital workspace where teams can write, plan, share and collaborate with the help of AI.

## Features

- Sticky navigation bar
- Responsive navigation links
- Hero section
- Gradient background
- Main heading and description
- Call-to-action buttons
- Dashboard preview image
- Floating information cards
- Tasks card
- Project Status card
- Team Activity card
- Fixed chat widget
- Responsive design
- Tailwind CSS utility classes


## Technologies Used

- HTML5
- Tailwind CSS
- CSS3
- JavaScript

## Tailwind CSS Concepts Used

The project demonstrates the following Tailwind CSS positioning utilities:

- `relative`
- `absolute`
- `sticky`
- `fixed`

Other Tailwind utilities used include:

- `p-*`
- `m-*`
- `px-*`
- `py-*`
- `mt-*`
- `mb-*`
- `bg-*`
- `text-*`
- `flex`
- `items-center`
- `justify-center`
- `z-*`
- `rounded-*`
- `shadow-*`
