To-Do List REST API

This project documents a RESTful API design for a To-Do List application. It includes the task resource model, CRUD endpoints, validation rules, status codes, and usage examples for a beginner-friendly API design.

API Endpoints

  • POST /api/tasks
  • GET /api/tasks
  • GET /api/tasks/:id
  • PATCH /api/tasks/:id
  • DELETE /api/tasks/:id
