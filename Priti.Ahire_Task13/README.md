# Even or Odd Number Checker

## About

This is a simple JavaScript program that checks whether a given number is **Even** or **Odd**.

The project uses **HTML, CSS, and JavaScript**.

## Files

* `index.html` – Creates the webpage.
* `style.css` – Adds simple styling.
* `script.js` – Checks whether the number is even or odd.

## How It Works

1. Enter a number in the input box.
2. Click the **Check Number** button.
3. The program checks the number using the `if-else` statement.
4. The result is displayed on the webpage.
5. The result is also shown in the browser console using `console.log()`.

## Formula

A number is **Even** if:

`number % 2 === 0`

Otherwise, the number is **Odd**.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a number and click **Check Number**.

## Technologies Used

* HTML
* CSS
* JavaScript

## Example

If you enter:

`10`

Output:

`10 is an Even Number`

If you enter:

`7`

Output:

`7 is an Odd Number`
