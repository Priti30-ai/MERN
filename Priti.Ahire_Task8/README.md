# LaundryCare Landing Page

## Overview

This project is a simple responsive landing page for a laundry service. It is built using HTML and CSS and demonstrates responsive web design techniques. The page includes a navigation bar, hero section, call-to-action button, and a mobile navigation menu.

The mobile menu is implemented using the CSS `:focus` pseudo-class on a button, without using JavaScript.


## Features

- Responsive layout for desktop and mobile devices
- Navigation bar with menu links
- Hero section with heading, description, and call-to-action button
- Mobile navigation using a hamburger button
- Mobile menu implemented using the CSS `:focus` pseudo-class
- No JavaScript used


## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional software or installation is required.


## Responsive Design

- Desktop view displays the complete navigation bar.
- Mobile view hides the navigation bar and displays a hamburger menu.
- Clicking the hamburger button shows the mobile menu using the CSS `:focus` pseudo-class.
