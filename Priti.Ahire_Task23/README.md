# Project Workspace - AI Landing Page

## Task 23 - Tailwind Mini Project

Project Workspace is a modern, minimal and responsive AI-powered
project management landing page created using HTML and Tailwind CSS.

## Objective

The website demonstrates an AI-powered workspace where users can:

- Write and organize ideas
- Plan projects and tasks
- Collaborate with team members
- Track project progress
- Get assistance from AI

## Technologies Used

- HTML5
- Tailwind CSS CDN
- JavaScript

## Positioning Utilities Demonstrated

### Relative Positioning

The CTA container and dashboard preview container use:

`relative`

This creates a reference point for absolutely positioned elements.

### Absolute Positioning

The CTA buttons and floating cards use:

`absolute`

This allows the elements to be positioned at specific locations.

### Z-Index

The dashboard and floating cards use:

`z-10`

and

`z-20`

This controls which elements appear above other elements.

### Fixed Positioning

The chat widget uses:

`fixed bottom-6 right-6 z-50`

This keeps the chat button at the bottom-right of the screen.

3. Open `index.html`.
4. Use Live Server to run the page.
5. View the website in a browser.
