
# Greenwood Library Website

## Task 23 - Tailwind Mini Project

Greenwood Library is a modern, minimal and responsive editorial-style
landing page created using HTML and Tailwind CSS.

## Objective

The website showcases the Greenwood Public Library's:

- Library sections
- Gallery
- Membership plans
- Community values
- Events
- Contact information

## Technologies Used

- HTML5
- Tailwind CSS CDN
- JavaScript

## Features

- Sticky navigation bar
- Backdrop blur navigation
- Responsive hero section
- Responsive statistics section
- Interactive library section cards
- Responsive image gallery
- Bento-style values section
- Editorial two-column About section
- Membership cards
- Popular membership badge
- Testimonial section
- Contact call-to-action
- Google Maps directions link
- Email contact link
- Events grid
- Multi-column footer
- Social media icon circles
- Hover animations
- Image zoom effects
- Responsive design
- Mobile navigation menu

## Tailwind Features Demonstrated

- `backdrop-blur-md`
- `max-w-7xl`
- `group`
- `group-hover`
- `transition-all`
- `transition-colors`
- `transition-transform`
- `hover:scale-105`
- `overflow-hidden`
- `columns-1`
- `sm:columns-2`
- `col-span-2`
- `grid-cols-1`
- `md:grid-cols-2`
- `lg:grid-cols-4`
- `after:w-0`
- `hover:after:w-full`
- Responsive utility classes

## Responsive Design

The website is designed for:

- Mobile
- Tablet
- Desktop

Tailwind responsive utilities such as `sm:`, `md:` and `lg:` are used.

## How to Run

1. Download or clone the project.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. View the website in a browser.
