# Task 4: CSS Units, Box Model and Fonts

## About the Project

This is my Task 4 project based on CSS Units, Box Model, Text Styling and Fonts.

I created a simple webpage with an image, heading, paragraph and button.

## Technologies Used

* HTML
* CSS

## CSS Concepts Used

### CSS Units

I used `vw` and `vh` units in this project.

* `vw` is used according to the width of the screen.
* `vh` is used according to the height of the screen.

For example, I used `25vw` for the left and right space and `10vh` for the top and bottom space.

### Box Model

The box model includes:

* Content
* Padding
* Border
* Margin

I used `box-sizing: border-box` so that the padding and border are included inside the given width and height. This helps keep the card within the screen size and avoids extra size that can cause scrolling.

### Text and Fonts

I used different font properties like:

* `font-family`
* `font-size`
* `font-weight`
* `line-height`
* `letter-spacing`

I used Georgia for the heading and Arial for the other text.

### Gradient

I used a gradient on the button with blue and purple colors. I chose these colors because they look good together and make the button stand out from the white card.

### Margin and Padding

I used margin to create space outside elements and padding to create space inside elements.

### Hover Effect

When the mouse is moved over the button, the gradient colors change.

## Features

* Uses `vw` and `vh` units.
* Demonstrates the CSS Box Model.
* Uses margin, padding and border.
* Uses different fonts and text styling.
* Includes a gradient button.
* Includes a hover effect.
* The page is designed to fit within the screen.
* Does not use Flexbox.
* Does not use absolute or relative positioning.
