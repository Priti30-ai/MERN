# Laundry Services Hero Section

This is a simple hero section made using HTML and CSS.

I created a navbar and a hero section for a laundry service website. The page includes a heading, description, button, and laundry-related image.

## Concepts Used

* `display: inline` for the navbar elements
* `float: left` for the hero content
* `position: relative` for the hero section
* `position: absolute` for the image
* Viewport units such as `vh` and `vw`

## Technologies

* HTML
* CSS

## Files

* `index.html`
* `style.css`

## How to Run

Open the `index.html` file in a browser.

## What I Practiced

In this task, I practiced using different CSS layout properties such as `display`, `float`, and `position` to arrange the elements on the page.
