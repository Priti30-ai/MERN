# Laundry Wallah / Laundry Mart

A simple and user-friendly laundry service webpage created using semantic HTML5.

## Project Overview

Laundry Wallah / Laundry Mart is a basic laundry service website that provides information about laundry services, pricing, and booking.

The webpage includes:

* Header section with the website title
* About Us section
* Laundry service image
* List of available services
* Price list displayed in a table
* Book Now form
* Footer with contact information

## Technologies Used

* HTML5

## Features

* Semantic HTML structure
* About section describing the laundry service
* Services list
* Price list with service charges
* Booking form with required fields:

  * Name
  * Email
  * Phone
* Contact email in the footer

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in any modern web browser.
4. The Laundry Wallah / Laundry Mart webpage will be displayed.

You can also run the project using **VS Code Live Server**:

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click inside the file.
4. Select **Open with Live Server**.
