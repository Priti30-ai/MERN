# Task 17 - Promise Based Division

## Objective

To create a JavaScript function that performs division using a Promise.

The function handles division by zero and returns either the result or an appropriate error message.

## Technologies Used

- HTML
- CSS
- JavaScript
- JavaScript Promises

## Features

- Takes two numbers as input.
- Performs division using a Promise.
- Resolves the Promise when division is successful.
- Rejects the Promise when the second number is zero.
- Uses `.then()` to handle the result.
- Uses `.catch()` to handle errors.
- Includes 5 test cases.
- Demonstrates the basic JavaScript Event Loop concept using `setTimeout()`.
