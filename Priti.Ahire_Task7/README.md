# Laundry Services Landing Page

## About the Project

This project is a simple responsive laundry services landing page created using HTML and CSS. The page contains a navigation bar, a hero section with text and an image, and a button for booking a service.

The layout is created using Flexbox. Media queries are used to make the page responsive on tablet and mobile screens.

## Features

* Responsive web page
* Flexbox layout
* Navigation bar
* Hero section
* Call-to-action button
* Mobile-friendly design

## Technologies Used

* HTML5
* CSS3

## Responsive Design

* Desktop: Navigation bar and hero section are displayed in two columns.
* Tablet (768px): Navigation remains horizontal with smaller text and spacing.
* Mobile (480px): Navigation links are hidden and the hero section changes to a single-column layout.
