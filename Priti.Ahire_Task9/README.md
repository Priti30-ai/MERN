# LaundryCare Transformation

## Overview

This is a simple landing page for a laundry service.  
The main goal was to practice CSS transforms on a button hover.

## Features

- Basic header with logo and navigation
- Hero section with text, image and a call-to-action button
- Button hover effect using `transform` (move, scale, rotate)
- Simple responsive layout for tablet and mobile

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Used

- Flexbox for layout
- Media queries for responsiveness
- `transform` and `transition` for hover effects

## Project Structure

LaundryCare-Transformation/
├── index.html
├── style.css
└── README.md

## How to Run

1. Put all files in one folder.
2. Open `index.html` in a browser.

## What I Learned

- How to build a simple responsive page with HTML and CSS
- Using Flexbox to arrange elements
- Adding hover effects with `:hover`
- Using `transform` to move, scale and rotate the button
- Making the layout work on smaller screens with media queries
