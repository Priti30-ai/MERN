# Laundry Services Web App

## About the Project

This project is a simple and responsive Laundry Services Web App.

The website allows users to:

- View available laundry services
- See the price of each service
- Add services to the cart
- Remove services from the cart
- View the total amount
- Enter booking details
- Book a laundry service
- Receive a booking confirmation email
- Subscribe to the newsletter

The website is designed to be simple, clean and easy to use.


## Technologies Used

- HTML
- CSS
- JavaScript
- EmailJS
- Font Awesome


## Features

### 1. Navigation Bar

The website contains a navigation bar with:

- Home
- Services
- About Us
- Contact Us
- User Name

The navigation bar is also responsive for smaller screens.

### 2. Hero Section

The hero section contains:

- Website heading
- Short description
- Book a Service button
- Laundry-related image

The button takes the user to the booking section.

### 3. Service Overview

The website displays some achievements such as:

- 15+ Laundry Services
- 240+ Happy Customers
- 2+ Years Experience

### 4. Laundry Services

Users can view different laundry services with their prices.

For example:

- Dry Cleaning
- Wash & Fold
- Ironing
- Stain Removal
- Leather & Suede Cleaning
- Wedding Dress Cleaning

Users can add or remove services from the cart.

### 5. Shopping Cart

The cart displays:

- Selected services
- Service prices
- Total amount

If no service is selected, it displays a message asking the user to add items.

### 6. Booking Form

The booking form asks the user to enter:

- Full Name
- Email
- Phone Number

After selecting a service and entering the required details, the user can click the **Book Now** button.

### 7. Email Confirmation

EmailJS is used to send the booking information through email.

The booking email contains:

- Customer name
- Customer email
- Phone number
- Selected services
- Total amount

After successful booking, the website displays:

> Thank you for booking the service. We will get back to you soon.

### 8. Quality Services

The website highlights:

- Premium Services
- Quick Support
- Timely Delivery
- Affordable Prices

### 9. Newsletter

Users can enter their name and email address to subscribe to the newsletter.

### 10. Footer

The footer contains:

- FreshFold logo
- About Us
- Important Links
- Contact information
- Social media icons
