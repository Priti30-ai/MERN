# JavaScript Array Operations

## About

This project performs basic operations on an array using JavaScript.

The program finds the maximum number, calculates the sum of all elements, and counts the number of odd numbers in the array.

## Array Used

[4, 8, 2, 11, 6, 7, 10]

## Operations Performed

- Find the maximum number in the array
- Calculate the sum of all elements
- Count the number of odd numbers
- Display the results using `console.log()`

## Function Types Used

- Arrow function
- Anonymous function
- Normal function

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder in VS Code.
2. Open the `index.html` file in a web browser.
3. Right-click on the page and select **Inspect**.
4. Open the **Console** tab.
5. Check the results displayed in the console.

## Expected Output

Array: [4, 8, 2, 11, 6, 7, 10]

Maximum number: 11

Sum of all elements: 48

Count of odd numbers: 2
