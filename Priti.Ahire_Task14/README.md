# JavaScript Number Operations

## Objective

This project is a JavaScript program that performs different mathematical operations on numbers using loops and conditional statements.

## Operations Performed

- Sum of first n natural numbers
- Multiplication table of a number
- Prime number checking
- Finding all factors of a number
- Sum of digits
- Armstrong number checking
- Reverse of a number

## Numbers Used

The program performs operations on five different numbers:

- 153
- 17
- 51
- 123
- 200

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.
3. Click the **Run Program** button.
4. Open **Developer Tools → Console**.
5. Check the console to view the results.

## Output

All operation results are displayed in the browser console using `console.log()`.
